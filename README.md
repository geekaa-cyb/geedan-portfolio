# Ra.M.Geedan — Personal Portfolio

A responsive, single-page portfolio for Ra.M.Geedan, a BCA student at Presidency University, Bengaluru. It highlights his interests in cybersecurity, web development, programming and creative work.

## Run

Open `index.html` directly in a modern browser. No installation, build step, or server is required.

## Personalize

- Replace the clearly labeled portrait placeholder with your own photograph.
- Add real project and creative-work examples when they are ready to share.
- Add your social profile links and contact details when you want them published.

The page uses Google Fonts and a temporary portrait image from Unsplash; those assets require an internet connection. The rest of the site is plain HTML, CSS, and JavaScript.
